{%- comment -%} Overrides minima 2.5's own header include. Nothing of minima's markup survives except the class names its stylesheet already paints (.site-header, .site-title), because the nav here is not minima's: it is four rooms as pixel icons, centred, and a stranger landing on the front page has to be able to see all four at once and guess right about which one they want. The rooms come from site.header_pages, so the order lives in _config.yml and each page carries its own gloss and icon in front matter. A page with no `nav_icon` still renders — label and gloss, no sprite — so adding a room cannot break the bar. No hamburger. Four icons fit one row at 320px, and a menu you have to open is exactly the thing this bar exists to stop being. {%- endcomment -%}
